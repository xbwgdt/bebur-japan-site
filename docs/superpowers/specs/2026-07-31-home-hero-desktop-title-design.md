# 首页主标题桌面端单行显示

## 目标

让首页主视觉的标题「水質とガスを、より確かに。」在桌面端以单行显示，同时保留平板与手机端的自动换行，避免窄屏文字溢出。

## 范围

- 只修改首页专用的 CSS 规则：`app/globals.css`。
- 只影响 `.source-home-hero .source-hero h1`。
- 不修改 `app/page.tsx` 中的日文文案。
- 不修改 Sanity schema、Sanity 数据或其他页面标题。

## 设计

在桌面断点（最小宽度 64rem / 1024px）新增首页主标题覆盖规则：移除当前的 `12ch` 最大宽度并启用 `white-space: nowrap`。这样标题可按完整语句排成一行。

现有基础规则继续适用于小于该断点的屏幕，因此标题仍可自动换行。若桌面测试发现容器中仍有边缘压迫，只允许在同一桌面规则中小幅下调响应式字号；不改变标题的字重、色彩、行高或其余首页布局。

## 验收标准

1. 在至少 1024px 宽度下，首页标题完整显示为单行。
2. 在手机宽度下，标题仍会自动换行，且没有横向滚动或内容截断。
3. 产品页、新闻页及其它组件的标题样式不受影响。
4. 生产构建与现有测试通过，并新增针对该桌面样式规则的回归测试。

## 风险与回退

风险仅限首页桌面主视觉的排版。若较窄桌面出现压迫，可调整该断点内字号；如需完全撤回，删除新增的桌面媒体查询即可恢复当前两行显示。
