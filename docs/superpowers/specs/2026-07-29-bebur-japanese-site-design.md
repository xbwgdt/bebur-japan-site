# Bebur 日本語公式サイト 設計仕様

作成日: 2026-07-29  
対象: Bebur 日本語公式サイト  
日本総代理店: 新樹産業株式会社

## 1. 目的

既存の Bebur 新版公式サイトを基に、112 ページの実コンテンツを日本市場向けに再構成する。単純な逐語翻訳ではなく、水質分析、ガス検知、清浄度測定などの専門領域で自然かつ信頼性の高い日本語 B2B サイトを構築する。

サイトの主な目的は次のとおり。

- Bebur の製品、技術、導入分野を日本語で分かりやすく紹介する。
- 製品選定に必要な型式、測定原理、用途、特長、仕様を整理する。
- 日本国内の問い合わせを新樹産業株式会社へ集約する。
- 日本市場でのブランド信頼性と検索上の発見性を高める。

## 2. 対象範囲

既存サイトの sitemap には約 874 URL が含まれるが、旧版、重複、過去の SEO 用ページが多数含まれる。新版英語サイトの 113 URL のうち 1 URL は言語切り替え処理であり実コンテンツではないため除外し、本サイトでは残る 112 ページの実コンテンツを移行する。旧版・重複ページと言語切り替え URL は移行しない。

対象コンテンツ:

- ホーム
- 製品カテゴリ一覧
- 製品詳細
- 導入分野
- 導入事例
- 企業情報
- 沿革、認証、展示会
- ニュース、技術情報
- お問い合わせ

対象外:

- 旧版 URL と重複コンテンツ
- 中国国内向け販売情報、WeChat、Douyin、ICP 登録情報
- 中国側の電話番号、メールアドレス、販売拠点情報
- 個人情報をサーバーへ保存する問い合わせフォーム
- 管理画面、会員登録、決済、外部データ連携

### 4.5 ニュース・技術情報

新版サイトに含まれるニュースと技術記事を日本語化し、一覧と詳細ページを用意する。記事は製品カテゴリまたは導入分野と関連付ける。公開日は原文の日付を維持し、原文にない事実や認証表現は追加しない。

## 5. ビジュアルデザイン

テーマは「精密計測 × 水と空気」とする。

- 主色: 深いネイビー、Bebur ブルー
- 補助色: 透明感のあるシアン、淡いブルーグレー
- 背景: 白を中心に、情報の階層を示す薄い寒色面
- 文字: 日本語可読性に優れたゴシック体
- レイアウト: 日本の製造業・計測機器サイトに適した整然としたグリッド
- 装飾: 細線、測定目盛、波形、水や空気を想起させる控えめなモチーフ

既存サイトのブランドブルーと製品認知を維持しながら、余白、文字サイズ、情報階層、モバイル操作性を現代化する。過度な装飾や派手なアニメーションは避ける。

製品画像は既存 Bebur サイトの新版ページに掲載されているものを優先して再利用する。用途イメージが必要な場合は、水処理、製薬、液冷、工場安全など実際の利用場面に合う写真を選び、製品画像と誤認される生成画像は使用しない。

## 6. 日本語化ルール

- 逐語翻訳ではなく、日本の技術者・購買担当者が自然に読める文章へローカライズする。
- 型式、数値、単位、測定範囲、測定原理は原文と一致させる。
- 原文にない性能保証、認証、法令適合、販売実績は追加しない。
- 専門用語をサイト全体で統一する。
- 中国語の販売表現や中国国内向け導線は削除する。
- 画像内に中国語が含まれる場合は、内容を確認し、必要に応じて日本語画像へ差し替えるか、画像外の日本語説明で補完する。

主要用語:

- 水质分析仪器 → 水質分析計
- 气体检测仪器 → ガス検知器
- 清洁度检测设备 → 清浄度測定装置
- 加药控制设备 → 薬注制御装置
- 行业应用 → 導入分野
- 工程案例 → 導入事例

## 8. コンテンツの流れ

既存 Bebur 新版サイトから対象ページのタイトル、本文、型式、仕様、画像、カテゴリ、公開日、関連情報を取得する。内容をページ種別ごとの共通データ形式へ整理し、日本語化した上で一覧・詳細ページから参照する。

ページ表示時は URL に対応するデータを読み込み、共通のヘッダー、パンくず、本文テンプレート、問い合わせ導線、フッターを組み合わせる。存在しない URL は明確な 404 ページへ案内し、製品情報またはホームへ戻れるようにする。

## 9. エラーと例外

- 製品画像が取得できない場合は、製品名を表示するブランド準拠の代替表示を使用する。
- 仕様情報が原文に存在しない場合は推測で補わず、その項目を省略する。
- 元ページが重複する場合は新版英語サイトの URL 構造を優先し、一つの日本語ページへ統合する。
- メールアプリを利用できない環境でも、メールアドレスをコピーできるよう文字で併記する。
- 電話リンクが利用できない端末でも、電話番号を選択・コピーできるよう表示する。
- 外部ページへのリンクは、公開前に到達確認し、不要な中国向け導線を除外する。

## 10. 検索と共有

- HTML 言語を日本語に設定する。
- 各ページに固有の日本語タイトルと説明を設定する。
- 製品詳細には型式と製品カテゴリを含める。
- 会社情報は新樹産業株式会社を日本総代理店として明示する。
- サイトマップと検索エンジン向け巡回設定を提供する。
- 共有プレビューは完成サイトの配色、見出し、製品分野を反映する。
- 正式ドメイン接続前は Railway が発行する確認用 URL で内容確認を行う。

## 11. アクセシビリティと表示対応

- デスクトップ、タブレット、スマートフォンに対応する。
- 色だけに依存せず、文字、線、形で状態を示す。
- 本文と背景のコントラストを確保する。
- すべての主要操作に分かりやすいラベルを付ける。
- 製品画像に日本語の代替テキストを付ける。
- キーボード操作時にフォーカス位置を視認できるようにする。
- 動きを減らす端末設定を尊重する。

## 13. 公開方針

本番環境は Railway を使用する。アプリケーションは Railway が提供する実行環境で起動できる構成とし、環境が割り当てるポートを使用する。初回は Railway が発行する確認用 URL へ公開し、ページ内容、画像、内部リンク、連絡先を確認する。

正式公開時は `www.bebur-jp.com` を Railway サービスへ接続する。DNS 操作は、Railway 上の確認用 URL で日本語サイトの受け入れ確認が完了した後に行う。DNS レコード、TLS 証明書、`www` とルートドメインの転送方針は、現在のドメイン管理状況を確認してから設定する。
