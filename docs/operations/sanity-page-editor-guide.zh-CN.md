# Sanity 页面编辑指南

本指南面向 Bebur 日本站的内容编辑人员。Studio 左侧导航中的“页面内容”用于维护落地页、关于我们、应用页、产品分类页、洞察列表页和联系页；“产品内容”“新闻内容”“站点设置”分别管理产品、新闻和全站公共信息。请从对应入口编辑，避免以新建页面替代已有页面。

## 编辑页面

1. 在“页面内容”中打开已有页面，或在确认需要新页面后新建页面。
2. 填写页面标题和 URL 标识。URL 标识只能使用小写英文字母、数字和连字符；已上线页面不要随意修改。
3. 在“页面模块”中按页面顺序添加或调整模块。每个模块可拖动排序，页面至少需要保留一个模块。
4. 在“SEO”页签填写 SEO 标题（10–60 个字符）和 SEO 描述（50–160 个字符）。面向日本用户的公开文案请使用日语；所有图片都必须填写日语替代文本。

## 页面模块与预设

可用模块如下：

- **Hero**：页面首屏，包含眉题、主标题、摘要、背景图和主/次行动按钮。
- **富文本**：连续正文、说明或列表。
- **图片画廊**：多张图片的展示区。
- **卡片网格**：并列的能力、行业或案例卡片。
- **数据表**：规格、参数或对比信息。
- **行动号召**：页面末尾的咨询、联系或下一步链接。

每个模块都提供受控的样式预设（颜色、字号、对齐、间距和桌面端标题换行）。请从下拉选项中选择预设，不要在文案中加入 HTML、内联样式或自行约定的颜色名称。使用与相邻模块一致的预设可以保持网站视觉统一；如确实需要新样式，请先交由开发团队评估。

## 发布流程

1. 完成内容和 SEO 自检后，先点击 Studio 右上角的保存操作。
2. 将“发布状态”设为“已发布”，再使用 Studio 右上角的 **Publish** 发布文档。只有同时满足这两个条件的页面会被公开站点读取。
3. 发布会触发生产构建 webhook。不要发布草稿或仅为测试而改动生产内容。
4. 等待 Cloudflare Pages 构建完成后，打开对应公开页面，检查标题、图片、链接、日语文案和手机端显示。若发现问题，修正后重新发布；紧急回退请联系负责发布的管理员。

## 发布前检查

- 页面标题、URL 标识、SEO 标题和 SEO 描述已填写。
- 每个页面模块均有完整内容；所有图片都有正确的日语替代文本。
- 链接指向当前站内路径或经确认的外部地址。
- 联系方式、公司名称及“站点设置”中的全站信息仅由授权人员修改。
- 不需要上线的内容保持“草稿”，不要仅为了验证流程而修改生产页面。
